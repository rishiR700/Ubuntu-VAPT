# Ubuntu VAPT

## Overview

This repository showcases a basic Vulnerability Assessment and Penetration Testing (VAPT) project conducted on Ubuntu systems in a controlled environment. The project focuses on identifying security vulnerabilities, evaluating potential risks, and documenting recommendations to improve system security.

## Objectives

- Identify security vulnerabilities.
- Assess the impact of discovered risks.
- Validate security weaknesses.
- Recommend appropriate remediation measures.
- Document the assessment findings.

## Basic Tools

- Terminal
- Nmap
- OpenVAS
- Wireshark

## Project Workflow

1. Information Gathering
2. Enumeration
3. Vulnerability Assessment
4. Risk Analysis
5. Remediation
6. Documentation
